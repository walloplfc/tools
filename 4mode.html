115 kV ±5% • MW PPA • MVAR @ 0.90 PF

สำหรับเรียนรู้และทบทวนข้อกำหนดเท่านั้น
หน้านี้ไม่เชื่อมต่อ PLC/NCC ไม่ส่งคำสั่งจริง การคลิกหรือเล่นอัตโนมัติเป็นการเดินบทเรียน ไม่ใช่การจำลองยืนยันสถานะอุปกรณ์

1. กำหนด MW PPA และ Limit

ใช้กำลังตามสัญญา PPA ไม่ใช่ Actual MW คำนวณ MVAR แบบสมมาตร Low = −Qmax / High = +Qmax ตามข้อกำหนดนี้

Voltage Limit 109.25–120.75 kV 115 × 0.95 ถึง 115 × 1.05
MW Limit รอ MW PPA Low = 0 / High = PPA
MVAR Limit @ 0.90 PF รอ MW PPA Low = −Qmax / High = +Qmax
Qmax = MW PPA × tan(acos(0.90)) = MW PPA × √(1 / 0.90² − 1) ≈ MW PPA × 0.484322
โหมดLowHighสัญญาณ

ปัดเฉพาะค่าที่แสดง คำนวณและตรวจด้วยค่าความละเอียดเต็ม Limit ตาม PPA ไม่ใช่การรับรอง Capability ของโรงไฟฟ้าทุกสภาวะ และไม่เปลี่ยน Communication Scale ให้อัตโนมัติ

2. Local Mode และ Cut-off Switch

DI STN_High/Low_CO_SW: Remote = 1 / Local = 0 ใช้กับ KV, MVAR, PF และ MW

KV/MVAR/PF เลือกได้ไม่เกินหนึ่งโหมด ส่วน MW เปิดร่วมได้ ตัวเลือกด้านล่างเป็นบทเรียนแยกจาก Flowchart ไม่ใช่สถานะจริง

3. Flowchart แบบ Interactive

คลิกกล่องเพื่ออ่านรายละเอียด • เส้นทางหลักแสดงกรณีคำสั่งสำเร็จ • ข้อยกเว้นที่ยังไม่กำหนดจะแสดงเป็นหมายเหตุ ไม่สร้าง Logic แทนโรงไฟฟ้า

4. ทดลองตรวจ Setpoint ของโหมดที่เลือก

ตรวจช่วงตัวเลขเท่านั้น ไม่ส่งคำสั่ง ไม่ Clamp และไม่ตัดสิน Permissive หรือ Capability จริง

5. I/O ของโหมดที่เลือก

ชนิดหมายเลข*Tagหน้าที่

DO/AO: NCC → โรงไฟฟ้า | DI/AI: โรงไฟฟ้า → NCC ชื่อบางจุดละ SDCE-P ชั้นนอก * AO แสดง Point ID; IOA จริงในเอกสารเดิมเป็น ### ต้องยืนยัน

6. ประเด็นที่ต้องยืนยันก่อนพัฒนา PLC

OFF MWRD แล้ว Feedback = 1 ตามข้อมูลล่าสุด

ข้อมูลล่าสุดระบุ OFF DO 6006 แล้ว DI STN_NCC/BNCC_MWRD = 1 ต่างจาก RD ของอีกสามโหมดที่เป็น 0 Flowchart จึงไม่ถือว่า RD ปิดสำเร็จ และไม่แก้เป็น 0 เอง ต้องยืนยันค่าที่ถูกต้องกับผู้ออกแบบ

PF Limit และ MVAR @ 0.90 PF
  • MVAR คำนวณจาก MW PPA คงที่ ไม่ใช่ Actual MW
  • เมื่อ Actual MW ต่ำกว่า PPA การใช้ MVAR ถึง Limit นี้ไม่ได้รับประกันว่า Actual PF เป็น 0.90
  • High PF = +0.90 และ Low PF = −0.90 ยังต้องยืนยันเครื่องหมาย Leading/Lagging และการแทน Unity PF
  • จึงไม่ตีความอัตโนมัติว่าทุกค่าระหว่าง −0.90 ถึง +0.90 เป็น Setpoint ที่อนุญาต
  • ต้องตรวจ Capability Curve และขีดจำกัดอุปกรณ์เพิ่มเติม
การเปลี่ยนโหมดและการกลับ Local
  • กำหนด Interlock และวิธีจัดการ Remote KV/MVAR/PF ที่สั่ง ON ซ้อนกัน
  • MW ทำงานร่วมโหมดอื่นได้ตามข้อกำหนดภาพรวม แต่ต้องระบุคู่ Remote/Local และ Remote/Remote ให้ชัดเจน
  • Sequence Remote MW ที่ให้มาระบุให้คงโหมดอื่นใน Local จึงยังไม่จำลอง Remote หลายโหมดพร้อมกัน
  • กำหนดผลเมื่อ Cut-off switch เปลี่ยนระหว่าง Remote และรายละเอียด High/Low side
  • กำหนดบทบาท RD, Timeout, Communication Failure และ Feedback Failure
  • Local MV “ค่าปัจจุบัน” หลังออกจาก KV/MVAR ต้องยืนยัน Actual MVAR หรือ Setpoint เดิม
  • หลังออกจาก PF ยังไม่ระบุค่าเริ่มต้น Local MV Setpoint
  • กำหนด Reject/Clamp/Hold สำหรับ Setpoint นอก Limit และการส่ง Alarm
  • กำหนด Setpoint Feedback ก่อนหรือหลังตรวจ Limit และ Ramp สำหรับเปลี่ยนโหมด
Tag และ Scaling ที่ต้องตรวจแก้
  • Sequence MVAR มีคำว่า Remote KV; หน้านี้ใช้ Remote MVAR ตามหัวข้อและสัญญาณ VAGC/SPMV
  • DO 6005: Sequence ใช้ PLC_SDCE-P AGC แต่ตารางเดิมใช้ STN_NCC/BNCC AGC
  • DI 10: Comment WAGC แต่ Tag AGC; DI 12: Comment MW ควรตรวจเป็น PF
  • AI 3 STN_MW SETTING ควรใช้หน่วย MW; AO 9002 ควรตรวจหน่วย MVAR; AO 9004 ควรเป็น PF
  • AI 6 SPMV และ AO/AI ของ KV ต้องตรวจ Raw Range และ Mapping
  • เมื่อเปลี่ยน PPA ต้องตรวจ Communication Scale ให้รองรับ MW และ MVAR Limit ใหม่
  • AI STN_115KV SETTING เป็นจุดรายงานค่า ต้องระบุตัวแปรควบคุมภายใน PLC ที่เชื่อมโยง
